Твой интернет. Твои правила.

Основной VPN, «Белые списки», вход через Telegram и график трафика.

## Обновление одной кнопкой

Когда выйдет новая версия, приложение покажет уведомление. Нажмите «Обновить»: оно скачает обновление, само закроет старую версию, заменит её и откроется снова. Ваш вход и профили сохранятся.

Крестик скрывает окно в трей, VPN продолжает работать. Для полного завершения выберите «Выйти и отключить VPN» в меню значка.

## Вход через Telegram

Для первого входа на новом ПК сканируйте QR-код телефоном и подтвердите вход в боте. Затем кнопка «Получить код доступа» в приложении отправляет четыре цифры в Telegram на телефон — введите их на ПК. Telegram на ПК открывать не нужно. Код одноразовый и действует до пяти минут. Мобильные версии также готовятся с подтверждением в боте; на Android TV — через QR-код с телефона. Никому не передавайте код входа.

## Настройки подключения Windows

Выберите русский или английский язык, программы (.exe), сайты и IPv4 для раздельного туннелирования. Доступны режимы «выбранные правила через VPN» и «выбранные правила обходят VPN». Программы и сайты объединяются; правила применяются при следующем подключении. Правила доменов используют DNS VPN: собственный Secure DNS браузера может мешать их работе. DNS и служебные проверки остаются защищёнными; IPv6 пока не поддерживается. Если включён другой VPN, исключённый трафик может идти через него.

VPN протокол: «Авто», «Основной · Xray», «Резервный режим». Авто проверяет основной VPN и при ошибке один раз пробует оплаченный резервный режим. Для резервного режима нужен действующий основной тариф и отдельный пакет белых списков.

## Важно при первом запуске

При первом переходе со старой версии завершите её через трей. Платный сертификат подписи кода пока не используется, поэтому Windows может показывать «Неизвестный издатель» или SmartScreen.

Лицензии компонентов входят в пакет. Личные ссылки, коды входа и ключи не публикуйте.
