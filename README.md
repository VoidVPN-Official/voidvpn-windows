# VoidVPN для Windows

Приложение VoidVPN для Windows 10/11 x64: основной VPN и режим «Белые списки», вход через Telegram, журнал подключения и график трафика.

## Скачать

Установщики и portable-сборки публикуются в разделе [Releases](https://github.com/dikem43212-oss/voidvpn-windows/releases). Первый релиз готовится к публикации после проверки.

Подписка и поддержка: [@VoidFastVPNBot](https://t.me/VoidFastVPNBot).

## Обновления

Эта страница предназначена для официальных выпусков VoidVPN. В новой версии приложения готовится уведомление об обновлении и установка одной кнопкой с сохранением аккаунта и профилей.

Крестик скрывает интерфейс в трей. Для полного завершения используйте «Выйти и отключить VPN» в меню значка VoidVPN.

## Состав выпуска

Каждый выпуск содержит установщик, portable-архив и описание изменений. Лицензии и исходники стороннего VK TURN транспорта включаются в portable-архив. Личные VPN-профили, ключи, данные бота и базы пользователей здесь не публикуются.
