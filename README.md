# VoidVPN

Твой интернет. Твои правила.

Основной VPN, «Белые списки», вход через Telegram и график трафика.

## Приложения

| Платформа | Статус | Получить приложение |
| --- | --- | --- |
| Windows 10/11 x64 | Доступна beta-версия 0.4.11 | [Последний релиз](https://github.com/dikem43212-oss/voidvpn-windows/releases/latest) |
| Android 8.0+ | Собрана предварительная версия 0.1.0; проверка на устройствах ещё не завершена | Публичный APK появится после проверки |
| Android TV | Подготовлены управление с пульта и вход по QR; требуется проверка на телевизоре | Пока не опубликовано |
| iPhone / iPad | Разрабатывается приложение; сборка и TestFlight ещё не выполнены | Пока не опубликовано |

Приложений VoidVPN в Google Play и App Store пока нет. Ссылки на магазины появятся здесь после публикации. Мобильные версии сохранят общий аккаунт и стиль приложения для Windows.

## Скачать для Windows

[Скачать последнюю версию](https://github.com/dikem43212-oss/voidvpn-windows/releases/latest)

Выберите установщик **VoidVPN-Setup** или распакуйте **portable** целиком и откройте VoidVPN.exe. Подписка и поддержка: [@VoidFastVPNBot](https://t.me/VoidFastVPNBot).

## Обновление одной кнопкой

Когда выйдет новая версия, приложение покажет уведомление. Нажмите «Обновить»: оно скачает обновление, само закроет старую версию, заменит её и откроется снова. Ваш вход и профили сохранятся.

Крестик скрывает окно в трей, VPN продолжает работать. Для полного завершения выберите «Выйти и отключить VPN» в меню значка.

## Вход через Telegram

В Windows доступны вход по четырём цифрам и QR-код: отсканируйте его телефоном и подтвердите вход в боте. Telegram на ПК для QR-входа не требуется. Мобильные версии также готовятся с подтверждением в боте; на Android TV — через QR-код с телефона. Никому не передавайте код входа.

## Важно при первом запуске

При первом переходе со старой версии завершите её через трей. Платный сертификат подписи кода пока не используется, поэтому Windows может показывать «Неизвестный издатель» или SmartScreen.

Лицензии компонентов входят в пакет. Личные ссылки, коды входа и ключи не публикуйте.
